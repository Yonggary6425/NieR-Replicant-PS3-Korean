# NieR Replicant (PS3) 한글패치

PS3 일본판 **NieR Replicant (ニーア レプリカント, BLJM60223)** 비공식 한글패치입니다.

- 제작: 용가리 ([@Yonggary6425](https://github.com/Yonggary6425))
- 번역·도구 제작 보조: Claude (Anthropic)
- 버전: v1.0

> 이 저장소에는 게임 데이터가 들어 있지 않습니다. 직접 덤프한 게임 파일이 있어야 하며,
> 패처는 사용자의 원본 파일에 **번역으로 바뀐 부분만** 적용합니다.

## 적용 방법

1. 게임을 폴더 형태로 덤프해 둡니다. (`PS3_GAME\USRDIR\MEDIA\STABLE.SDAT` 가 있어야 함)
2. [Releases](../../releases/latest)에서 `NieR_Replicant_PS3_Korean_v1.0.zip`을 받아 압축을 풉니다. (게임 폴더 옆에 두면 자동으로 찾습니다)
3. `한글패치적용.bat` 을 더블클릭합니다.
   - 게임 폴더를 못 찾으면 경로를 물어봅니다. 게임 폴더를 bat 파일 위에 끌어다 놓아도 됩니다.
   - 4.3GB `STABLE.SDAT` 중 바뀌는 부분만 다시 암호화해 덮어씁니다. 몇 초면 끝납니다.
   - 덮어쓰기 전의 원본 바이트는 `backup\` 에 자동 저장됩니다.
4. 원래대로 돌리려면 `원래대로되돌리기.bat` 를 실행합니다. 원본과 바이트 단위까지 똑같이 복구됩니다.

### 참고
- **RPCS3**: 트로피가 이미 설치돼 있으면 `dev_hdd0\home\00000001\trophy\NPWR01132_00` 폴더를 지운 뒤 실행해야 한글 트로피가 다시 설치됩니다.
- **RPCS3 컷신 자막 싱크**: 컷신에서 자막과 음성이 어긋나면 RPCS3 게임별 설정의 주사율(Hz) 값을 조정하세요. 패치가 아니라 에뮬레이터 속도 문제이며, 설정을 바꾸면 해결됩니다.
- **실기(CFW)**: 다시 암호화한 SDAT의 서명 일부가 원본과 다릅니다. RPCS3에서는 정상 동작을 확인했지만, 실기에서는 아직 확인하지 못했습니다.
- 다른 판본(북미판 Gestalt 등)에는 적용되지 않습니다. 패처가 원본을 확인하고 다르면 중단합니다.

## 저장소 구성

```
patcher/NierKoPatch.ps1                   패처 본체 (Windows PowerShell 5.1 이상)
patch/STABLE_ko.nrkd                      차분 패치 데이터 (번역문·한글 폰트·UI 이미지의 바뀐 바이트만)
patch/TROP_ko.SFM                         한글 트로피 정의
translation/                              번역표(일본어↔한국어), 번역 지침, 용어집
tools/                                    패치 제작 도구 (Python): SDAT 복호화/재암호화, CPK, 폰트, 텍스처
```

실행용 `한글패치적용.bat` / `원래대로되돌리기.bat` 는 Releases의 zip에 들어 있습니다.

## 패치 원리

1. `STABLE.SDAT`(NPD 암호화)를 16KB 블록 단위로 복호화하면 CRI CPK 아카이브가 나옵니다.
2. 텍스트는 UTF-8 탭 구분 파일이고, 폰트는 유니코드 맵 + 1024×1024 4채널 텍스처입니다.
3. 번역문과 한글 글리프를 넣은 뒤, 원본과 달라진 바이트만 `STABLE_ko.nrkd` 에 저장했습니다.
4. 패처는 해당 블록만 복호화 → 원본 해시 확인 → 차분 적용 → 결과 SHA1 확인 → 재암호화 → 블록·메타데이터·헤더 해시 갱신 순서로 처리합니다.
